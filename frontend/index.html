Actuators Traverse corridor to adjacent node, inspect physical room, update agent position, replan route upon negative outcome.

Heuristic Admissibility & Consistency Guarantees

1. Goal Condition: $h(g, g) = 0$ for all goal states $g$.

2. Admissibility: $h(n, g) \le h^*(n, g)$, where $h^*(n, g)$ is the true shortest path cost. Guarantees A* returns the cost-optimal path.

3. Consistency (Monotonicity): By the triangle inequality of Euclidean space, for any edge $(u, v)$ with weight $c(u, v)$ and goal $g$:

h(u, g) ≤ c(u, v) + h(v, g)

Because the straight-line Euclidean distance between any two connected campus nodes is $\le$ the corridor's walking weight $c(u, v)$, Euclidean distance is mathematically both admissible and consistent. No node reopening is required in A*.

Failure Cases & Scalability Analysis

Unreachable Destinations: When corridors are blocked or a room is cut off from the graph, BFS, Greedy, and A* exhaust their frontiers and return success = False without crashing. Candidate planner assigns infinite priority score and moves unreachable rooms to the bottom of the visit order.

Scalability & The TSP Problem: Finding the exact globally shortest sequence to inspect $k$ rooms is an instance of the NP-hard Travelling Salesperson Problem ($O(k!)$). The agent utilizes a Greedy Nearest-Neighbor approximation ($O(k^2)$), balancing computation speed with practical routing.
